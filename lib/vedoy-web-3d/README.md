# Vedoy Web 3D Engine

**Developed by Vedoy Studio**. General-purpose Web 3D runtime for interactive articles, websites, experiences, and games. VeDo is one potential consumer, not the name of the engine.

## Engine
- Three.js renderer; framework-independent TypeScript core
- Scene schema with clickable object events
- Camera interpolation for scroll-driven stories
- Resize handling, GPU cleanup, low-power pixel ratio

## Project creator defaults
- Framework: **Vedoy Framework**
- Language: **VedoyScript**
- Styling: **CSS**
- Available choices: Vedoy Framework, VedoyScript, TypeScript, JavaScript, HTML, CSS, React, Vue, Next.js.
- Note: HTML and CSS are document/style technologies, not JavaScript alternatives. React, Vue and Next.js are framework choices.
- VedoyScript and Vedoy Framework are **proposed integration contracts**, not yet implemented compilers or production-ready runtimes. Do not advertise them as working until built.

## Dependencies
`npm install three`
`npm install -D @types/three`
